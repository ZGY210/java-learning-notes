# 01 · 包装类与自动装箱

> 对应黑马 174 ｜ 学完填三问，合上笔记能讲出来才算过。

## 一、它是什么

> 包装类把基本类型（int/boolean/…）包成一个对象，8 个基本类型各有对应：**Byte、Short、Integer、Long、Float、Double、Character、Boolean**
> 为什么需要它？→ 集合不能存基本类型，泛型要对象

## 二、它为什么存在（面试必答）

- **自动装箱**：`Integer a = 100;` 底层是 `Integer.valueOf(100)` ——因为发生了 **编译期自动把基本类型转成包装对象** 。
- **自动拆箱**：`int b = a;` 底层是 `a.intValue()` —— 与装箱相反，自动把包装对象转回基本类型。
- **Integer 缓存**：`valueOf` 在 -128~127 返回缓存对象，之外 `new`。为什么设计缓存？→ **日常高频小整数复用对象，减少堆上重复创建，大幅节省内存、提升性能** 。
- **坑**：`==` 比的是引用地址；`equals` 才是比值。所以 `new Integer(100) == new Integer(100)` 是 false.

## 三、什么场景 / 有什么坑

- **拆箱 NPE**：`Integer n = null; int m = n;` 抛 __NPE__ ，因为拆箱自动调 `n.intValue()`，null 调用方法直接空指针。
- **Map 陷阱**：`int total = map.get("key")` 当 key 不存在（返回 null）时拆箱会 直接抛 NPE
- **三目运算符**：`Integer r = flag ? v : 0;` 一边 Integer 一边 int，自动把整条表达式提升为 int，v 为 null 就 触发隐式拆箱，直接 NPE。
