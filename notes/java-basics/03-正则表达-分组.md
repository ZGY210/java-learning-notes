# 捕获分组 与 非捕获分组

> 复制本文件，改名为 `主题-知识点.md`，存到对应目录（`java-basics/` `collections/` `concurrency/` `jvm/`）。
> **每篇笔记只回答三个问题**，答不出来就回去看视频那一段。

## 一、它是什么

> 正则表达的分组运用

## 二、它为什么存在（解决了什么问题）

> 是为了让"把子表达式当成一个整体"和"是否需要提取/引用这段子匹配"分开控制

## 三、什么场景用它、有什么坑

> 捕获分组: 1.提取结构化数据 2.替换时重排 3.反向引用 4.命名捕获,提高可读性 
>
> 非捕获分组: 1.避免污染捕获序号 2.减少无用结果和内存
>
> 坑: 1.编号按左括号顺序,嵌套也计组
