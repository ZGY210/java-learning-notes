# 01 · 网络分层与数据封装

> 对应《计算机网络面试手册》D1 ｜ 学完填三问，合上笔记能讲出来才算过。

## 一、它是什么（分层模型）

> 为什么要分层？一句话：每层只解决一类问题,上不用关心下怎么运行

**TCP/IP 四层表**（自己默画，别抄）：

| 层     | 主要协议                | 解决什么                      |
| ----- | ------------------- | ------------------------- |
| 应用层   | _HTTP、DNS、SMTP、SSH_ | __业务语义__                  |
| 传输层   | TCP、UDP             | 端到端、进程到进程（端口号在这一层）        |
| 网络层   | __IP、ICMP、ARP__     | 主机到主机（IP 地址在这一层）          |
| 网络接口层 | __以太网、WiFi__        | __同一链路上怎么发帧__（MAC 地址在这一层） |

## 二、它为什么存在（解决了什么问题）

> 换掉 WiFi 用 4G，HTTP 代码一行不用改 —— 因为 每层只解决一类问题,上不用关心下怎么运行

## 三、什么场景 / 有什么坑（面试追问）

- 三次握手发生在哪一层？→ 传输层
- ping 用什么协议？→ ICMP
- 为什么 TCP 头有端口而 IP 头没有？→ 端口是是**进程**的标识，所以端口在传输层。IP负责将包送到主机
