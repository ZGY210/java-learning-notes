# 06 · HTTP/1.1 vs 2 vs 3

> 对应《计算机网络面试手册》D6 ｜ 学完填三问。

## 一、横向对比

| | HTTP/1.1 | HTTP/2 | HTTP/3 |
|---|---|---|---|
| 传输层 | __ | __ | __（QUIC，基于UDP） |
| 队头阻塞 | 有 | TCP层仍有 | 基本消除 |
| 多路复用 | 否（开多个连接） | 一个连接多流 | 一个连接多流 |
| 头压缩 | 无 | __ | __ |
| 建连 | TCP+TLS 各一轮 | 同1.1 | __-RTT |

## 二、为什么

- HTTP/1.1 的队头阻塞：一个连接一次只能处理一个请求，排队。浏览器只能开多个连接缓解（默认 6）。
- HTTP/2 用「多路复用」在一个 TCP 连接上并行请求，解决了应用层队头阻塞。
- **但 TCP 层的队头阻塞还在**（一个包丢了，同一 TCP 上所有流都等）。这正是 HTTP/3 改 UDP + QUIC 的原因。
