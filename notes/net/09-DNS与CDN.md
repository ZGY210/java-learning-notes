# 09 · DNS 与 CDN

> 对应《计算机网络面试手册》D9 ｜ 学完填三问。

## 一、它是什么

> DNS 把 **域名** 翻译成 **IP 地址** 。
>
> CDN 把静态资源放到 **离用户最近（各地边缘）** 的节点上。

## 二、DNS 解析顺序（必背）

> 浏览器缓存 →系统缓存（hosts / OS 缓存） → 本地 DNS 服务器（路由器/运营商） → 根域名服务器 → 顶级域名服务器（.com） → 权威域名服务器

**追问**：**DNS 查询走 TCP 还是 UDP？** → **默认走 UDP 53 端口** （报文超 512 字节或区域传送时用 TCP）

## 三、什么场景 / 有什么坑

> 一次网页加载里，DNS 解析最耗时间的是哪一步？→ **访问根域名服务器** （递归链条最长，本地缓存未命中时最慢）
> CDN 怎么加速？→ 就近返回（把资源缓存到离用户最近的边缘节点）+ 智能调度（按 IP/延迟选最优节点）
