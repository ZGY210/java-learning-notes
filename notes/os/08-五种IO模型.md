## 三、select / poll / epoll 三兄弟

| | select | poll | epoll |
|---|---|---|---|
| 最大 fd 数 | 1024 | 无上限 | 无上限 |
| 每次调用是否要把 fd 集合从用户态拷进内核 | 是 | 是 | **否（一次注册）** |
| 内核怎么找就绪的 fd | 遍历全部 | 遍历全部 | **回调 + 就绪链表** |
| 适合场景 | fd 少 | fd 中等 | **fd 多且活跃少（高并发）** |
