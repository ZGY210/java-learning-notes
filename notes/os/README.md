## 三条铁律

1. **每篇笔记必须有一栏「和 Java 的关系」**。OS 是给你后面学并发和 IO 打地基的，不是拿来背的。写不出这一栏，说明你只是在抄。
2. **能用自己电脑验证的，一定要验证**。比如 D1 就让你跑 `java -version` 确认自己是不是 JDK 21 —— 因为虚拟线程那一条和你本机直接相关。
3. **不许攒**。每天 30 分钟当天写完，攒到周末写等于没写。
