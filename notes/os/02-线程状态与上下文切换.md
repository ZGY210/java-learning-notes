## 五、动手验证（5 分钟，必须做）

在 `D:\Agent工作\Java学习\P1-JavaSE\code\p1-javase` 下新建一个临时文件跑一下，不用提交：

```java
public class StateCheck {
    public static void main(String[] args) throws Exception {
        Thread t = new Thread(() -> {
            try { Thread.sleep(2000); } catch (InterruptedException e) { }
        });
        System.out.println("new 之后      : " + t.getState());   // NEW
        t.start();
        Thread.sleep(200);
        System.out.println("sleep 中      : " + t.getState());   // TIMED_WAITING
        t.join();
        System.out.println("结束之后      : " + t.getState());   // TERMINATED
    }
}
```

## 六、和 Java 的关系（**必填**）

| OS 概念 | Java 里对应什么 | 在哪用到 |
|---|---|---|
| 线程状态机 | `Thread.State` 六个枚举值 | `jstack` 打出来的就是这些状态 |
| 上下文切换 | 无法直接观测，但 `jstack` 里大量 `RUNNABLE` + 高 CPU = 可能切换过多 | 线程池调优 |
| 调度 | JVM 不参与，交给 OS；但线程**优先级**（1–10）会映射到 OS 优先级 | **不要依赖优先级做业务逻辑** |
| 时间片 | 影响「为什么我的循环没跑完就被切走了」 | 并发可见性问题 |
