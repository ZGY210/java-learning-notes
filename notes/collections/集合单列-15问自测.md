| 1   | ArrayList 和 LinkedList 的底层结构分别是什么？                                     | ArrayList ：底层是 动态数组 。LinkedList ：底层是 双向链表 。                                                                                                                                                                                          | 1   |
| 2   | ArrayList 的扩容规则是什么？为什么是 1.5 倍而不是 2 倍？                                  | 新容量 = 旧容量 + (旧容量 >> 1) ，也就是 旧容量的 1.5 倍 ，向下取整。2 倍扩容浪费空间太多，1.5 倍在“扩容次数”和“浪费空间”之间取得较均衡的平衡。                                                                                                                                              | 1   |
| 3   | 为什么 ArrayList 查询快、增删慢？（从内存和数组移动两个角度）                                   | ArrayList 底层是 Object[],连续 + 等长.                                增删慢:核心不是“内存操作慢”，而是“要移动后面的元素”。                                                                                                                                         | 1   |
| 4   | LinkedList 的 Node 里存了什么？为什么它是双向链表？                                     | Node =  数据 + 前指针 + 后指针 。因为单向链表没法高效做“从尾部/中间往前”的操作，而 JDK 要求 LinkedList 的 API 前后都对称。                                                                                                                                                    | 1   |
| 5   | 用普通 `for (int i = 0; i < list.size(); i++) list.remove(i)` 删元素会怎样？为什么？ | 删不干净，会漏删.remove(i) 之后，后面的元素全部往前挪一格，但 i 还是在 i++ 往前走。正解：用 Iterator 迭代器删                                                                                                                                                                | 1   |
| 6   | 迭代器的 `remove()` 为什么合法？fail-fast 是靠哪个字段实现的？                             | 因为  Iterator.remove() 会在删除后，把 expectedModCount 同步更新成最新的 modCount ，让两个数重新对齐。                                                                                                                                                          | 1   |
| 7   | `Arrays.asList()` 的三个坑分别是什么？                                           | ①  不能增删 （内部类没实现 add/remove，抛 UnsupportedOperationException）；②  是原数组的视图 ，改 list 改数组互相影响；③  传基本类型数组会整体当一个元素 ，size 变成 1。解法是套一层 new ArrayList<>(Arrays.asList(...))，基本类型用包装类或 Stream。                                                    | 1   |
| 8   | `List.of()` 和 `Arrays.asList()` 有什么区别？                                 | Arrays.asList() 是固定长度的数组视图，能 set 不能增删，允许 null，改它会同步影响原数组；List.of() 是完全不可变的独立集合，任何修改都抛异常、不允许 null、JDK 9 才有。要真正可增删的都得套一层 new ArrayList<>()。                                                                                            | 1   |
| 9   | `list.remove(1)` 和 `list.remove(Integer.valueOf(1))` 有什么区别？            | remove(1) 调的是 remove(int index)——删下标 1 的元素；remove(Integer.valueOf(1)) 调的是 remove(Object o)——删“值等于 1”的那个元素。  重载不同，行为完全不同。                                                                                                             | 1   |
| 10  | ArrayList 是线程安全的吗？不安全会出什么问题？怎么变成安全的？                                   | ArrayList 不是线程安全的：并发 add 会因 size++ 非原子导致 元素覆盖丢失 ，扩容竞争会抛 越界异常 ，遍历时被改会抛  ConcurrentModificationException 。修法有三种：Collections.synchronizedList() 全局加锁（遍历仍需手动同步）、CopyOnWriteArrayList 写时复制（读多写少最优，读无锁不抛 CME）、或者干脆避免共享、线程内各用各的。Vector 不推荐。 | 0   |
| 11  | 数组 `int[]` 和 `List<Integer>` 之间怎么互转？（写出两种方向）                           | int[] → ListArrays.stream(arr).boxed().collect(Collectors.toList())  List → int[]list.stream().mapToInt(Integer::intValue).toArray()                                                                                                 | 1   |
| 12  | LinkedList 能当队列和栈用吗？靠哪个接口？各用哪个方法？                                      | LinkedList 实现 Deque 接口，所以队列栈都能当。当 队列 用 offer() 入队 poll() 出队（FIFO，尾进头出）；当 栈 用 push() 压 pop() 弹（LIFO，头进头出）。                                                                                                                            | 0   |
| 13  | ArrayList 的 `elementData` 为什么用 `transient` 修饰？                         | elementData 是扩容机制留下的"大桶"，有效元素只有 size 个。用 transient 屏蔽默认序列化，改由 writeObject/readObject 只写 size 个有效元素，避免把大量 null 空槽和错误的数组类型写进流里—— 这是所有"内部数组 + 动态容量"集合的通用套路 。                                                                            | 0   |
| 14  | `new ArrayList<>()` 和 `new ArrayList<>(0)` 在第一次 add 时行为有什么不同？          | new ArrayList<>() 第一次 add 会按 DEFAULT_CAPACITY = 10 扩容，new ArrayList<>(0) 第一次 add 不会立刻给 10，而是按“从 0 开始按 1.5 倍涨”的规则扩到 1，之后 1→2→3→4→6→9→13……  这就是最核心的区别。                                                                                 | 1   |
| 15  | 遍历 List 有哪 5 种方式？各自适用于什么场景？                                            | 遍历 List 有：普通 for（要下标、限随机访问集合）、增强 for（只读最常用）、Iterator（遍历中删除）、ListIterator（双向 + 可 set + 有下标）、forEach/Stream（函数式、可并行）。判据就三条： 要不要下标、要不要边遍历边改、集合是不是 LinkedList 。                                                                          | 1   |
