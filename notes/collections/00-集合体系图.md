## 三、`Iterable` vs `Iterator`（这页要能背出来）

- `Iterable`：说明一个对象「可以被遍历」，只有 1 个方法：`________()`
- `Iterator`：遍历器本身，有 3 个方法：`________()` / `________()` / `remove()`
- 两者的关系：集合实现 `Iterable`，它的 `iterator()` 方法**返回**一个 `Iterator` 对象。

`for (String s : list)` 编译后等价于：

```java
for (Iterator<String> it = list.iterator(); it.hasNext(); ) {
    String s = it.next();
    // 循环体
}
```
