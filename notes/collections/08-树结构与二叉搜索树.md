## 一、它是什么

### 三种树一句话 + 区别表

| 树 | 一句话 | 特点 |
|---|---|---|
| 二叉树 | 每个节点最多两个子节点 | 对节点值没有约束 |
| 二叉查找树（BST） | 左小右大 | 左子树所有值 < 根 < 右子树所有值 |
| 平衡二叉树（AVL） | BST + 左右子树高度差 ≤ 1 | 防止退化成链表 |

### 三个术语

- **深度** = 从根到该节点的边数
- **高度** = 从该节点到最深叶子的边数
- **中序遍历** = 左 → 根 → 右

## 二、它为什么存在（面试分界线）

### 1. 为什么 BST 的中序遍历天然升序？

> 提示：BST 的定义是「左子树所有值 < 根 < 右子树所有值」。中序先输出左（都小）、再根、再右（都大）。

### 2. BST 最坏情况是什么？为什么需要平衡二叉树？

> 提示：按 1,2,3,4,5 顺序插入，BST 会退化成一条链表，查找变 O(n)。平衡二叉树（AVL）通过旋转保持高度差 ≤ 1，让查找稳定在 O(log n)。

### 3. 为什么 `TreeMap` 和 `HashMap` 都跟树有关？

> 提示：TreeMap 底层是红黑树（一种平衡 BST），保证 key 有序；HashMap 在链表太长时（≥8）会「树化」成红黑树，防止哈希冲突退化成 O(n)。这两个就是后面两周的重点。
