# journal/ —— 学习日志与周复盘

> **这是简历上唯一无法造假的东西。** 面试官翻你的 GitHub，看到连续 200 天的日志，比看到任何一句「学习能力强」都有说服力。

---

## 一、文件命名

```
journal/
├── 2026-10-16.md               # 每日日志：YYYY-MM-DD.md
├── 2026-W42-周复盘.md          # 周复盘：YYYY-Www-周复盘.md（ISO 周数）
├── _template.md                # 空模板
└── README.md
```

**为什么不再用 `-D1` / `-D2`**：「集合的 D1」和「常用 API 的 D1」会撞名。原来的 `2026-10-13-D1.md` 已改名成 `2026-10-13.md`。

### 日志文件由教练每天预生成（2026-10-16 起）

**你不用自己建日志文件。** 教练会在前一天把下一天的日志建好，里面已经写好当天的任务表和证据清单，你只需要填「三行」。

想自己建也可以：`.\newday.cmd` 会按当天日期从 `_template.md` 生成一个空文件。

完整模板见：[../../../P0-准备期/03-学习日志与周复盘模板.md](../../../P0-准备期/03-学习日志与周复盘模板.md)

## 二、每日日志：只写 3 行，5 分钟

**不要写日记。** 不要写「今天学了集合，收获很多」。只写这三行：

```markdown
## 今天写了什么代码
（具体到文件名和方法名：「给 MyArrayList 加了 modCount，跑通 fail-fast 那条测试」）

## 今天搞懂了什么（能不看笔记说出来的才算）
（只写你真的能不看书讲清楚的。讲不清楚的，写进 notes/待补-知识漏洞.md）

## 今天卡住 / 明天第一件事
（明天坐下第一件事做什么，写具体动作，不写「继续学集合」）
```

**为什么只写 3 行**：写日志的成本越低，越可能坚持 200 天。写成 800 字的作文，第 5 天就断了。

## 三、周复盘：每周日 30–45 分钟

五步，照做：

| 步骤 | 时间 | 做什么 |
| --- | --- | --- |
| 1 | 5 min | 翻本周所有笔记的**标题**（不是内容），回忆讲了什么 |
| 2 | 15 min | **闭卷自测 5 个知识点**，写到纸上。答不出来的立刻记进 `notes/待补-知识漏洞.md` |
| 3 | 5 min | 整理漏洞清单，按优先级排序 |
| 4 | 10 min | 写周总结：本周 commit 数 / 题数 / 交付物 / 最大收获 |
| 5 | 5 min | 定下周调子：**提速**还是**回补**（二选一，必须选） |

---

## 四、三个数字（每周必看）

| 数字 | 含义 | 低于这个数说明什么 |
| --- | --- | --- |
| **commit 数** | 本周真实动手次数 | **< 5 → 这一周是「假学习」** |
| 新增笔记数 | 本周搞懂的知识点 | 0 → 只在看视频，没有输出 |
| 刷题数 | 算法手感 | 0 → 笔试会挂 |

**规则：可以中断，但绝不能连续断 2 天。** 生病、考试、赶作业都允许断 1 天；断第 2 天，习惯就断了。
