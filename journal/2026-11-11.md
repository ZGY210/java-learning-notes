## 五、今天的三个自问（合上视频和笔记回答）

1. TreeSet 判重靠的是什么？和 HashSet 差在哪？
   → TreeSet 只看  compareTo 返回 0 ，返回 0 就当成同一个元素拒绝加入，根本不调用 equals。HashSet 则靠  hashCode() + equals()  两个方法：先散列定位桶，桶里再用 equals 精确比。差别在于—— 当 compareTo 返回 0 但 equals 返回 false 时，TreeSet 认为“同一个”，HashSet 认为“不同” ，两个集合互转就可能丢元素。

2. `record` 为什么不能用来演示「不重写 equals 会怎样」？
   → 因为 record  编译器自动帮你生成了 equals、hashCode、toString ，而且按所有字段逐个比较。你就算不手写，它也已经重写完了，演示不出“不重写 equals 导致去重失效”的效果。要演示这个问题，得用一个 普通类 （只写字段、不重写 equals），才会出现两个内容相同但 equals 为 false、被当成不同对象的坑。
