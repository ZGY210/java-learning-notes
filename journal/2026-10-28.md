## ② 代码任务详情（今天的重头戏，80 min）

链表没有下标，所有操作都是「从头顺着 next 走」。今天 8 个方法的核心就是三种指针操作：

1. **走到某个节点**：`Node cur = head; for (int i = 0; i < index; i++) cur = cur.next;`
2. **插到 index-1 后面**：`newNode.next = prev.next; prev.next = newNode;`（顺序不能反）
3. **删掉 index**：让 index-1 跳过它：`prev.next = prev.next.next;`

**反转链表（面试最高频，务必能默写）**——三指针套路：

```java
Node prev = null;
Node cur = head;
while (cur != null) {
    Node next = cur.next;   // ① 先记住下一个，别把链弄断
    cur.next = prev;        // ② 掉头
    prev = cur;             // ③ prev 前进
    cur = next;             // ④ cur 前进
}
head = prev;
```

> 最容易错的顺序：先改 `cur.next` 再去拿 `cur.next`。记住「**先记 next，再掉头**」。
