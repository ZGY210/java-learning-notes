## ② 代码任务详情（今天的重头戏，80 min）

链表没有下标，所有操作都是「从头顺着 next 走」。今天 8 个方法的核心就是三种指针操作：

1. **走到某个节点**：`Node cur = head; for (int i = 0; i < index; i++) cur = cur.next;`
2. **插到 index-1 后面**：`newNode.next = prev.next; prev.next = newNode;`（顺序不能反）
3. **删掉 index**：让 index-1 跳过它：`prev.next = prev.next.next;`

**反转链表（面试最高频，务必能默写）**——三指针套路：

```java
Node prev = null;
Node cur = head;
while (cur != null) {
    Node next = cur.next;   // ① 先记住下一个，别把链弄断
    cur.next = prev;        // ② 掉头
    prev = cur;             // ③ prev 前进
    cur = next;             // ④ cur 前进
}
head = prev;
```

> 最容易错的顺序：先改 `cur.next` 再去拿 `cur.next`。记住「**先记 next，再掉头**」。

**验收**：`main` 里 10 条自查全绿，其中第 9 条验证反转，第 10 条验证越界抛异常。

## 二、今天搞懂了什么（能不看笔记说出来的才算）

- 链表没有下标，所有操作都归结为三种指针动作：走到某节点（`for` 循环 `cur = cur.next`）、插入（`newNode.next = prev.next; prev.next = newNode;`，顺序不能反）、删除（`prev.next = prev.next.next;`，让前一个跳过它）。
- 反转链表的核心是「先记 next，再掉头」：先改 `cur.next` 再取 `cur.next`，链就断了。三个指针 `prev`（已反转部分）、`cur`（当前掉头的节点）、`next`（还没动的部分），循环结束 `cur == null` 时 `prev` 就是新头，要返回/赋给 `prev` 而不是 `head`。
- 能一句话说清栈、队列、数组、链表四种数据结构各自的特点和典型类：栈（后进先出，`Deque`/`ArrayDeque`）、队列（先进先出，`ArrayDeque`/`LinkedList`）、数组（连续内存、随机访问快，`int[]`/`ArrayList`）、链表（节点+指针、增删快、查询要顺 next 走，`LinkedList`）。
