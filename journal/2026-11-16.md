## 今日三个必须能答出来的问题

1. **Map 和 Collection 是什么关系？**（答：没关系，两套体系 —— 但要说清 Map 的 key 是怎么存的）
    没有继承关系，是两套独立体系。Collection 存单列元素，Map 存键值对。要说清 key 怎么存的：Map 内部把 key 单独拿出来，靠 key.hashCode() 算哈希定位到数组下标（桶），冲突时同一桶内用 equals 比较。所以 key 是 靠 hashCode 定位、靠 equals 判等 存的，这也解释了为什么自定义对象当 key 必须同时重写这两个方法。
3. 三种遍历分别靠什么 API？哪一种最快？为什么？
    遍历一：keySet() + get(k)
    遍历二：entrySet() + getKey()/getValue()
    遍历三：forEach((k, v) -> ...)
    entrySet 最快 。因为它在一次遍历中就把 key 和 value 都拿到了；而 keySet+get 每个元素还要额外调一次 get(k)，重新算哈希、定位桶、比对 key，等于查了两遍表。数据量大时差距明显。
5. **`map.put(k, v)` 当 k 已存在时返回什么？**（不是 null，是旧值 —— 面试常问）
    返回 旧值 （被覆盖掉的 value）。k 不存在时才返回 null。面试常考，因为很多人误以为 put 总返回 null。
