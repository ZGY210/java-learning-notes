### 第一件事（30 min）：补懒初始化

JDK `ArrayList` 的构造器**不会立刻开数组**：

```java
// JDK 8 源码
private static final Object[] DEFAULTCAPACITY_EMPTY_ELEMENTDATA = {};
private static final Object[] EMPTY_ELEMENTDATA = {};
transient Object[] elementData;

public ArrayList() {
    this.elementData = DEFAULTCAPACITY_EMPTY_ELEMENTDATA;   // 空的，长度 0
}
```

你现在两个构造器都是**立刻 `new Object[...]`**。改成 JDK 的做法：

1. 加两个静态常量 `EMPTY_ELEMENTDATA`（无参构造用）和 `DEFAULTCAPACITY_EMPTY_ELEMENTDATA`（其实 JDK 是两个，你至少要做到「无参构造不分配数组」）。
2. `add` 里第一次扩容时，判断「数组还是那个空数组」→ 按 `Math.max(DEFAULT_CAPACITY, minCapacity)` 开 10。

**验收方法**（写进 `main` 或单独跑）：

```java
MyArrayList<String> l = new MyArrayList<>();
System.out.println(l.size());   // 0
l.add("a");                     // 到这里才真正开数组
```
