1. 15 问里我错得最多的是哪一类？是记不清、理解错，还是没学过？
   → 多数是「记不清细节」而不是「没学过」 ——扩容 1.5 倍、asList 的固定长度 vs 不可变、fail-fast 靠 expectedModCount 这些你都写出了正确意思，说明概念建立了，问题在“复述的精度”。真正值得标成“理解错”的只有  第 5 题普通 for 删元素 那一条（你把它写成了元素不挪 + i 不动的混淆表述）。这题拿下就该重点复习。

2. 三次反转为什么能把「循环移位」变成「局部翻转」？我能不能用一句话讲清楚？
   → 循环移位本质是把数组“切成两段再交换顺序”，而“交换两段”可以等价成三次翻转——整体翻转把两段顺序换过来了，但每段内部也被倒序了；再把两段各自翻一次，内部顺序还原，整体就完成了两段交换。

3. 操作系统这个模块，我为什么要现在学，而不是等 12/27 学并发时再学？
   → 因为 并发是在 OS 的机制之上搭起来的 ：线程的状态（新建/就绪/运行/阻塞/终止）就是 OS 线程状态；上下文切换、临界区、锁、IO 模型全都是 OS 概念在 Java 里的投影。等到 12/27 学并发时再倒着补，等于先背 API 再补原理，理解会浮在表面。现在学 OS 锚点，是把地基先打牢，后面学并发是“顺着原理往下落”，而不是“逆着补课”。
