# 0006. 手写冒泡 + 选择排序的「讲清楚」

> 今天不只是写对，还要能讲。面试会连着问这两句，先答上来再说代码：
>
> 1. 冒泡排序的"冒"到底冒的是什么？
> 2. 选择排序和冒泡排序，哪个交换次数少？为什么？
>    把答案写进这一段。

---

## 一、冒泡排序

### 过程（自己默画）

> 每轮把未排序区里最 **大** 的冒到末尾。第 k 轮结束后，末尾 k 个已经有序。

### 代码

```java
void bubbleSort(int[] a) {
     for (int i = 0; i < a.length - 1; i++) {
            for (int j = 0; j < a.length-1-i; j++) {
                if (a[j] > a[j+1]) {
                    int temp = a[j];
                    a[j] = a[j+1];
                    a[j+1] = temp;
                }
            }
        }
}
```

### 复杂度与交换

- 时间：O(**n²**)
- 交换次数：最坏 **n*(n-1)/2** 次

---

## 二、选择排序

### 过程

> 每轮从未排序区里找最 **小** 的下标，和未排序区 **头部** 的元素交换。

### 代码

```java
void selectionSort(int[] a) {
    for (int i = 0; i < a.length - 1; i++) {
            int min = i;
            for (int j = i + 1; j < a.length; j++) {
                if (a[j] < a[min]) {
                    min = j;
                }
            }
            int temp = a[min];
            a[min] = a[i];
            a[i] = temp;
        }
}
```

### 复杂度与交换

- 时间：O(n²)
- 交换次数：每轮最多 ___1 次，共 n-1___ 次 —— **比冒泡少**，因为不是每对比一次就交换

---

## 三、对比（重点！）

|     | 比较次数  | 交换次数（最坏） | 稳定性 |
| --- | ----- | -------- | --- |
| 冒泡  | O(n²) | O(n²)    | 稳定  |
| 选择  | O(n²) | O(n)     | 不稳定 |

> 所以：**选择排序交换少**（适合"交换代价高"的场景），但**不稳定**；冒泡稳定但交换多。
> 面试第一个追问往往就是「为什么选择排序不稳定」—— 举例子：
>  {5a, 3, 5b, 1}，第一轮选中最小的 1 和 5a 交换，5b 就跑到 5a 前面了——相对顺序被破坏。
>

---

## 四、今天的收获一句话

> ______
>
> 冒泡靠相邻交换把大数逐步挪到末尾，天然稳定；选择排序只在每轮末尾做一次交换，交换次数极少，但跨位置交换会直接破坏相等元素的相对顺序，天生不稳定。
