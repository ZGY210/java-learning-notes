# 49. 字母异位词分组

> 难度：中等 ｜ 归属：LeetCode 60 题 · 阶段三（哈希与字符串）#19 ｜ 日期：2026-11-17
> 关键词：**Map 分组**、key 的设计、排序 / 计数

---

## 一、题目（自己用一句话复述）

给定一个字符串数组 `strs`，把**字母异位词**分到同一组里。

> 字母异位词：两个单词字母种类和数量完全相同，只是顺序不同。如 `eat` / `tea` / `ate`。

我的复述：

```
把每个单词的字母排序后作为 key，字母只要组成相同就会被分到同一个 list 里，最后返回所有 list。
```

示例：

- 输入 `["eat","tea","tan","ate","nat","bat"]` → `[["bat"],["nat","tan"],["ate","eat","tea"]]`
- 输出组的顺序、组内顺序都**不要求**（这点很重要，别为顺序纠结）

---

## 二、思路（两版都要写）

### 版本一：排序后的字符串当 key（最直观）

**核心想法**：异位词排序后必然完全相同 → 排序结果是天然的分组 key。

```
for (String s : strs) {
    char[] cs = s.toCharArray();
    Arrays.sort(cs);
    String key = new String(cs);      // ← key
    map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
}
```

我的实现（自己写）：

```java
public List<List<String>> groupAnagrams(String[] strs) {
    Map<String, List<String>> map = new HashMap<>();
    for (String s : strs) {
        char[] cs = s.toCharArray();
        Arrays.sort(cs);
        String key = new String(cs);                       // 排序后当 key
        map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
    }
    return new ArrayList<>(map.values());
}

```

**复杂度**：

- 时间：O(n · k log k)
- 空间：O(n · k)

### 版本二：计数数组当 key（更优，面试加分）

**核心想法**：26 个字母各出现几次，这个「计数向量」也是唯一的 key。

```
int[] cnt = new int[26];
for (char c : s.toCharArray()) cnt[c - 'a']++;
String key = Arrays.toString(cnt);    // ← 最省事的 key 化方式
```

我的实现（自己写）：

```java
public List<List<String>> groupAnagrams(String[] strs) {
    Map<String, List<String>> map = new HashMap<>();
    for (String s : strs) {
        int[] cnt = new int[26];
        for (char c : s.toCharArray()) {
            cnt[c - 'a']++;                                 // 每个字母出现几次
        }
        String key = Arrays.toString(cnt);                  // 计数向量当 key
        map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
    }
    return new ArrayList<>(map.values());
}

```

**为什么更快？**（填：排序是 k log k，计数是 k）

```
排序要 O(k log k)，计数只要 O(k)。  两者外层都要遍历 n 个单词，所以整体从 O(n·k log k) 降到 O(n·k)。字母固定 26 个，计数是线性扫描，不涉及比较排序。
```

**⚠️ 细节坑**：`Arrays.toString(cnt)` 会得到 `[1, 0, 0, ...]`；如果你自己拼字符串，**必须加分隔符**，否则 `[1,11]` 和 `[11,1]` 会撞车。

## 三、踩的坑（今天必须至少写 2 条，写真实的）

1. new String(cs) 才能把 char[] 转成字符串，cs.toString() 得到的是地址，导致所有 key 都变成 [C@...，全部混进一组。
2. computeIfAbsent 里如果只写 map.computeIfAbsent(key, k -> new ArrayList<>()); 却 漏掉 .add(s) ，返回的 map 全是空 list。
3. 版本二里 cnt[c - 'a']++：c - 'a' 是把 'a'~'z' 映射到 0~25，如果写成 cnt[c]++ 会数组越界（字符的 ASCII 值远大于 25）。
