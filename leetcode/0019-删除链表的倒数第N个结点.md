# 0019. 删除链表的倒数第 N 个结点（中等）

> 链表第 4 题。**双指针间隔 N** 的经典套路，面试常考。
> 填不出来的段落不要删，写「还没想明白：……」比留空有用。

链接：https://leetcode.cn/problems/remove-nth-node-from-end-of-list/

---

## 一、思路

### 我自己先想到的（笨办法）

> ① 第一反应：不知道长度就找不到倒数第 n 个，所以先完整遍历一遍数出 `len`，再从头走到第 `len - n` 个节点，把它的 `next` 跳过。  
> ② 复杂度：时间 O(n)（走两遍）、空间 O(1)。  
> ③ 卡在哪：要遍历两遍，`n` 变了就得重新数；而且删的是头节点（`len - n == 0`）时要特判，容易写崩。

**提示**：最直观的是「先走一遍数长度，再走第二遍删」。要两遍 O(n)。能不能一遍？

### 更好的做法（双指针间隔 N）

> 顿悟点： **不需要知道总长度，只要让两个指针之间始终保持 n 个节点的间距** ，那么 fast 到末尾时，slow 自然就落在倒数第 n 个的前面。用"距离"替代了"计数"。
>
> `dummy → fast = dummy`；fast 先走 `n+1` 步；fast、slow 同步前进直到 `fast == null`；此时 `slow.next` 即待删节点，执行 `slow.next = slow.next.next`。
>
> （注意：要 fast 先走 **n+1** 步，而不是 n 步，这样 slow 才停在"前一个"上，而不是"待删节点"上。）

**提示**：两个指针 `fast` 和 `slow`，先让 `fast` 往前走 N 步，然后两个一起走。当 `fast` 走到末尾（null）时，`slow` 正好在「倒数第 N+1 个」——即要删的节点的前一个。让 `slow.next = slow.next.next` 就删掉了。

### 为什么它能成立

> fast 和 slow 一起走时，两者间距固定为 `n+1`。当 fast 走到 `null`（末尾的下一位）时，slow 距离末尾也是 `n+1` 步，于是 slow 正好是倒数第 `n+1` 个，也就是倒数第 n 个节点的 **前驱** ——直接改 `next` 就删了。

**提示**：fast 和 slow 之间永远保持 N 的距离。fast 走到末尾时，slow 距离末尾也是 N —— 所以 slow 的下一个就是要删的。

### 为什么要用虚拟头节点 dummy？

> 删除目标可能是真头节点。有 dummy 时 `slow` 从 dummy 出发，它的前驱场景被统一进来，代码里不需要 `if (head == null)` 或"删除头节点单独处理"的分支；最后返回 `dummy.next` 就是新头。没有 dummy 时，想删头就得让 `head = head.next`，与删中间节点的写法不一致，容易漏。---

## 二、复杂度

| 版本   | 时间   | 空间   |
| ---- | ---- | ---- |
| 两遍遍历 | O(n) | O(1) |
| 双指针  | O(n) | O(1) |

推导过程（不要只写结果）：

- 时间：两遍遍历各走 O(n)，合计 O(n)；双指针也走一遍 O(n)，常数更小。  
- 间：只用了几个指针变量（`dummy`、`fast`、`slow`），不随 n 增长，O(1)。

## 三、代码

### 版本一：两遍遍历（能过）

```java
class Solution {
    public ListNode removeNthFromEnd(ListNode head, int n) {
        // 第一遍数长度，第二遍删
        ListNode dummy = new ListNode(0, head);

        int len = 0;
        for (ListNode cur = head; cur != null; cur = cur.next) {
            len++;
        }

        ListNode prev = dummy;
        for (int i = 0; i < len - n; i++) {
            prev = prev.next;
        }
        prev.next = prev.next.next;

        return dummy.next;
    }
}

```

### 版本二：双指针 + dummy（最优）

```java
class Solution {
    public ListNode removeNthFromEnd(ListNode head, int n) {
        // dummy → 先让 fast 走 n 步 → fast、slow 一起走 → slow.next = slow.next.next
        ListNode dummy = new ListNode(0, head);
        ListNode fast = dummy;
        ListNode slow = dummy;

        // fast 先走 n+1 步，让 slow 落在待删节点的前一个
        for (int i = 0; i <= n; i++) {
            fast = fast.next;
        }

        while (fast != null) {
            fast = fast.next;
            slow = slow.next;
        }

        slow.next = slow.next.next;
        return dummy.next;
    }
}

```

## 四、踩坑

> 这一栏是四段里**最值钱**的。

- [x] 坑 1：没加 dummy，删头节点时特判写崩。
- [x] 坑 2：fast 只走了 n-1 步就一起走，slow 停在了要删的节点上而不是它前面。
- [x] 坑 3：返回了 `head` 而不是 `dummy.next`（删了头节点时 head 已经不对了）。
