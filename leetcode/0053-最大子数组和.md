## 一、思路

### 我自己先想到的（笨办法）

> ① **第一反应** ：枚举所有子数组 `[i, j]`，把每个子数组的和都算一遍，取最大。
>
> ② **复杂度** ：三层循环（i、j、再求和）是 **O(n³)** ；用 **前缀和** 可以省掉内层求和，降到 **O(n²)** ，空间 O(n) 存前缀和（或 O(1) 迭代维护）。
>
> ③ **卡在哪 / 为什么不够好** ：n = 10⁵ 时，O(n³) 是 10¹⁵ 次、O(n²) 是 10¹⁰ 次， **都超时** 。问题是"没有复用已经算过的结果"，每个子数组都从头算，重复劳动太多。

### 更好的做法

> **关键顿悟点** ：不要枚举子数组，而是 **只关心"以 i 结尾的最大子数组和"** 。

**提示**：定义 `dp[i]` = 「以 `nums[i]` 结尾的最大子数组和」。那么 `dp[i]` 和 `dp[i-1]` 是什么关系？—— 要么接上前面的，要么自己单独开一个子数组：

```
dp[i] = max(dp[i-1] + nums[i], nums[i])
```

### 为什么它能成立

> 为什么只需要看 `dp[i-1]`，不用回头扫？
>
> 因为如果 `dp[i-1]` 是负数，把它接到 `nums[i]` 前面 **只会让和变小** ，不如让 `nums[i]` 自己单开。也就是说：
>
> - `dp[i-1] > 0` → 接下它有利，`dp[i] = dp[i-1] + nums[i]`；
> - `dp[i-1] <= 0` → 拖后腿，`dp[i] = nums[i]`。
>
> 这个式子自动涵盖了两者（`max` 帮你选）。 **"以 i 结尾的最优解只依赖 i-1 的最优解"** ——这种「局部最优 = 全局最优」的无后效性，就是这题能用 DP 的根本原因。

**提示**：如果 `dp[i-1]` 是负数，接上它只会让和变小，不如自己单开。这个「局部最优 = 全局最优」的性质，就是这题能用 DP 的原因。

## 二、复杂度

| 版本  | 时间    | 空间   |
| --- | ----- | ---- |
| 笨办法 | O(n²) | O(n) |
| DP  | O(n)  | O(1) |

推导过程（不要只写结果）：

- 时间：
  - 笨办法：枚举所有起点 i（n 次）和终点 j（n 次），每个子数组用前缀和 O(1) 取和，共 **n²/2 ≈ O(n²)** 。
  - DP：从 i=0 到 n-1 扫一遍，每个位置只做一次 `max` 和加法，共 **n 次** ，即 **O(n)** 。
- 空间：
  - 笨办法：要存前缀和数组，长度 n+1， **O(n)** （若用迭代变量维护前缀和可降到 O(1)）。
  - DP（朴素版）：要开 `dp[n]` 数组， **O(n)** 。

**加分**：DP 的空间能不能压到 O(1)？（提示：`dp[i]` 只依赖 `dp[i-1]`，只需要一个变量滚动。）

能。因为 `dp[i]` **只依赖 `dp[i-1]`** ，不需要整个数组，只用一个变量滚动即可——用 `cur` 表示"以当前元素结尾的最大和"

## 三、代码

### 版本一：能过的（笨办法）

```java
// 前缀和枚举所有子数组，先确保能过（小数据）
public int maxSubArray(int[] nums) {
    int n = nums.length;
    int[] prefix = new int[n + 1];
    for (int i = 0; i < n; i++) {
        prefix[i + 1] = prefix[i] + nums[i];  // prefix[i] = 前 i 项和
    }
    int max = Integer.MIN_VALUE;
    for (int i = 0; i < n; i++) {
        for (int j = i; j < n; j++) {
            int sum = prefix[j + 1] - prefix[i]; // 子数组 [i, j] 的和
            max = Math.max(max, sum);
        }
    }
    return max;
}

```

### 版本二：DP（O(n) 时间 / O(1) 空间）

```java
// 单变量滚动，写下你的版本
public int maxSubArray(int[] nums) {
    int cur = nums[0];        // 以当前元素结尾的最大子数组和
    int max = nums[0];        // 全局最大值（用 nums[0] 初始化，别用 0）
    for (int i = 1; i < nums.length; i++) {
        cur = Math.max(cur + nums[i], nums[i]); // 要么接，要么自己开
        max = Math.max(max, cur);               // 先更新 cur，再更新 max
    }
    return max;
}

```

## 四、踩坑

> 这一栏是四段里**最值钱**的。

- [ ] 坑 1：初始化 `max` 用了 `0` 而不是 `nums[0]` —— 全负数组会返回 0，答案是最大的那个负数。
- [ ] 坑 2：`dp[i]` 和「全局最大值」混在一起更新，忘了两个要分开记。
- [ ] 坑 3：滚动变量更新顺序写反（先更新了 max 才更新 cur）。
