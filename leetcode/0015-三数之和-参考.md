## 一、三个前置，你已经会了两个

### ① 你会「两数之和」的暴力：`nums[i] + nums[j] == target`
### ② 你会「移动零」的**快慢双指针**：一个指针只往前，另一个记录该写哪
### ③ 三数之和 = **排序 + 固定一数 + 双指针夹逼**

核心：要找 `a + b + c = 0`，先**排序**把数组变有序，然后：

```
固定 a = nums[i]                             （第一层 for）
  在 i 右边的一小段区间 [i+1, R] 里，用两个指针
  L 从左往右、R 从右往左，找 b + c = -a
```

排序让「双指针夹逼」成立——这是整道题的钥匙。

## 二、从最小的「找出一个满足 a+b+c=0 的三元组」写起

先别管判重，先让**一个**答案能出来：

```java
// 在 i 固定后，右边这段像"移动零"一样，用两个指针走
int target = -nums[i];
while (left < right) {
    int twoSum = nums[left] + nums[right];
    if (twoSum == target) {
        res.add(List.of(nums[i], nums[left], nums[right]));
        left++;
        right--;
    } else if (twoSum < target) {
        left++;          // 和太小 → 左指针往右走，让和变大
    } else {
        right--;         // 和太大 → 右指针往左走，让和变小
    }
}
```

**双指针为什么能这样走？因为数组有序**：`left` 右移和变大，`right` 左移和变小。你不需要 `for` 套 `for`。

## 三、完整版（含判重）

```java
public List<List<Integer>> threeSum(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    if (nums == null || nums.length < 3) return res;
    Arrays.sort(nums);

    for (int i = 0; i < nums.length - 2; i++) {
        // ① 定 a
        if (i > 0 && nums[i] == nums[i-1]) continue;   // 去重：跳过相同的 a

        int left = i + 1, right = nums.length - 1;
        int target = -nums[i];
        while (left < right) {
            int sum = nums[left] + nums[right];
            if (sum == target) {
                res.add(Arrays.asList(nums[i], nums[left], nums[right]));
                // ② 去重 b 和 c：跳过相等的
                while (left < right && nums[left] == nums[left+1])  left++;
                while (left < right && nums[right] == nums[right-1]) right--;
                left++;
                right--;
            } else if (sum < target) {
                left++;
            } else {
                right--;
            }
        }
    }
    return res;
}
```

## 四、三处「为什么」—— 面试官就爱问这三句

1. **为什么要排序？**
   排序让数组有序，双指针才能「left 右移和变大、right 左移和变小」地夹逼，把 O(n³) 降到 O(n²)。

2. **为什么外层要 `nums[i] == nums[i-1]` 时 continue？**
   因为 i 和 i-1 的 a 相同，两边找出来的三元组会重复。**跳过相同的 a** 就是去重。

3. **为什么找到一组后，左右指针还要 while 跳过相同值？**
   否则同一个 b 换成另一个相同的 b，会得到重复三元组。**排序 + 跳过相邻相等值** 是这道题去重的全部秘密。

---

## 五、复杂度

- 时间：排序 O(n log n) + 外层 for O(n) × 内层 while O(n) = **O(n²)**
- 空间：结果之外 O(1)（排序原地）

---

## 六、对照你会的

- 不像「两数之和」用 HashMap —— 因为还要**去重**，HashMap 管理重复很麻烦。
- 更像「移动零」的双指针 —— 但这里是**双向**双指针，一个从左、一个从右。

**一句话记忆**：排序 + 三层循环压成两层（外层定 a，内层双指针夹逼找 b+c），去重靠「跳过相邻相等值」。
