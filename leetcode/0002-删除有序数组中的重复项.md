# 0026. 删除有序数组中的重复项（简单）

## 一、思路

### 我自己先想到的（笨办法）

> 新建一个数组或使用哈希表，遍历原数组，把没有见过的元素存进去，最后再覆盖原数组。

### 更好的做法

> 双指针(快慢指针).

### 为什么它能成立

> 题目明确说明了是有序数组，这意味着重复的元素一定是相邻的。因此我们不需要记住所有出现过的数字，只需要用 fast 指针去探路，用 slow 指针去记录当前不重复元素应放置的位置。

---

## 二、复杂度

| 版本  | 时间   | 空间   |
| --- | ---- | ---- |
| 笨办法 | O(n) | O(n) |
| 更优解 | O(n) | O(1) |

推导过程（不要只写结果）：

- 时间：快指针 fast 从左到右遍历整个数组一次，每个元素最多被访问一次。慢指针 slow 只在遇到不重复元素时移动，因此总操作次数与数组长度 n 成正比。
- 空间：我们是在原数组 nums 上进行的修改，除了 slow 和 fast 两个整形指针变量外，没有开辟任何额外的数组或哈希表，因此空间复杂度不变。

## 三、代码

### 版本一：能过的（笨办法）

```java

public int removeDuplicates(int[] nums) {
    if (nums == null || nums.length == 0) return 0;

    Set<Integer> seen = new HashSet<>(); // 记录"见过"的元素
    int k = 0;                            // 下一个待写入位置

    for (int num : nums) {
        if (seen.add(num)) {   // add 返回 true 表示之前没见过
            nums[k++] = num;   // 原地覆盖
        }
    }
    return k;
}

```

### 版本二：更优的

```java

    public int removeDuplicates(int[] nums) {
        int n = nums.length;
        if (n == 0) {
            return 0;
        }
        int fast = 1, slow = 1;
        while (fast < n) {
            if (nums[fast] != nums[fast - 1]) {
                nums[slow] = nums[fast];
                ++slow;
            }
            ++fast;
        }
        return slow;
   }
```
