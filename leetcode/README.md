# leetcode/ —— 每日一题的题解归档

这个目录只放 **题解（markdown）**，不放 Java 源码。

> 为什么不放源码？因为题解是要给人看思路的，而源码是要能跑的。题解里贴的代码块可以直接复制到 IDEA 里跑，但归档的形态以「思路能讲清」为准。

---

## 命名规范

**四位编号-题目名.md**，例如：

```
0001-两数之和.md
0026-删除有序数组中的重复项.md
0146-LRU缓存.md
```

四位编号是为了让文件按题目号自然排序，跟 LeetCode 的题号对得上。题目名用中文，跟 LeetCode 中文站的标题一致，方便搜索。

---

## 每篇题解必须的四段

见 `_模板.md`。四段之外可以加，但不能少：

1. **思路** —— 你先想到的笨办法是什么，卡在哪
2. **复杂度** —— 时间 / 空间，要有推导过程，不是抄一句 O(n)
3. **代码** —— 至少两版（能过的 + 更优的）
4. **踩坑** —— 你实际写错的地方。这一栏是四段里最值钱的，面试官问「你踩过什么坑」时，答案从这里来

## 三个铁律（抄自清单文件，放在这里就是要天天看见）

1. **单题思考上限 30 分钟**，超时看题解，但看完必须关掉题解自己重写一遍。
2. **每题至少两版**：先写「能过」的，再想「有没有更优解」。
3. **一周后重做做错的题**。做对一次不算会，一周后还能做对才算会。
