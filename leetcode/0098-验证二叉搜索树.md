## 一、思路

### 我自己先想到的（笨办法）

> — BST 要求的是「**整棵**左子树 < 根 < **整棵**右子树」，不是「左孩子 < 根 < 右孩子」。
>
> ① 第一反应是“比较根和左右孩子”，即 `left.val < root.val < right.val` 对每个节点都成立。
>
> ② 复杂度 O(n)，每个节点访问一次。
>
> ③ 卡在 **只看直接孩子** ——反例：
>
>             5
>            / \
>           1   4
>              / \
>             3   6
>
> 节点 3、6 各自和 4 比都合法，但 4 在 5 的 **右子树** 里却比 5 小，整棵树不是 BST，这种写法会误判成 `true`.

### 更好的做法（两种）

**做法 A · 中序遍历递增**：BST 的中序遍历天然升序（你昨天刚写过）。所以只要中序遍历一遍，检查每个值都比前一个大。

**做法 B · 上下界递归**：每个节点带着一个合法范围 `(min, max)`。根的范围是 `(-∞, +∞)`；左孩子范围变成 `(min, root.val)`；右孩子范围变成 `(root.val, max)`。任何一个节点越界就是非法。

### 为什么它能成立

> **提示**：BST 的定义本身就是递归的——「左子树所有值 < 根 < 右子树所有值」。「所有值」怎么一次性保证？就是给每个子树传一个取值范围。这样每个节点只需检查自己是否在范围内，而不必回看祖先。

## 二、复杂度

| 版本    | 时间   | 空间           |
| ----- | ---- | ------------ |
| 中序遍历  | O(n) | O(h)，最坏 O(n) |
| 上下界递归 | O(n) | O(h)，最坏 O(n) |

推导过程（不要只写结果）：

- 时间：每个节点恰好访问一次，且只做 O(1) 比较，故 O(n)。
- 空间：只用递归栈，深度等于树高 h；平衡树 O(log n)，退化成链表（BST 最坏情况）时 O(n)。

## 三、代码

### 版本一：中序遍历递增

```java
class Solution {
    // 用 long 记录上一个值（初值 Long.MIN_VALUE），
    // 中序遍历中一旦出现「当前值 <= 上一个值」就返回 false
    private long prev = Long.MIN_VALUE;

    public boolean isValidBST(TreeNode root) {
        if (root == null) return true;
        if (!isValidBST(root.left)) return false;   // 左
        if (root.val <= prev) return false;         // 中：必须严格大于前驱
        prev = root.val;
        return isValidBST(root.right);              // 右
    }
}

```

### 版本二：上下界递归

```java
class Solution {
    public boolean isValidBST(TreeNode root) {
        return check(root, null, null);   // 用 null 表示 -∞ / +∞
    }

    // check(node, min, max): node.val 必须在 (min, max) 开区间内
    private boolean check(TreeNode node, Integer min, Integer max) {
        if (node == null) return true;
        if (min != null && node.val <= min) return false;
        if (max != null && node.val >= max) return false;
        // 左子树收紧上界为 node.val，右子树收紧下界为 node.val
        return check(node.left, min, node.val)
            && check(node.right, node.val, max);
    }
}

```

## 四、踩坑

> 这一栏是四段里**最值钱**的。

- [ ] 坑 1：只比较当前节点和左右孩子，漏了「整棵子树」的约束（经典错解）。
- [ ] 坑 2：用 int 记录「上一个值」导致溢出 / 边界错误，应该用 long 或 null。→ `int prev = Integer.MIN_VALUE` 遇到根节点值恰好是 `Integer.MIN_VALUE` 时会误判 false，必须用 `long` 或 `TreeNode prev = null`。
- [ ] 坑 3：边界用闭区间 `[min, max]` 写成了开区间 `(min, max)`——BST 不允许相等值，所以是**开区间**。→ 判断条件必须是 `node.val <= min` 和 `node.val >= max`，写成 `<` / `>` 会让 `[2,2,2]` 这种重复值用例通过。
